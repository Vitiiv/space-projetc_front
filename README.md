
# 🌌 Alura Space

Um projeto desenvolvido com Django, utilizando conceitos de rotas, templates, views, formulários e integração com banco de dados.  
O objetivo do projeto é criar um catálogo de imagens do espaço, onde é possível visualizar fotografias, cadastrar novas imagens, editar e remover registros — implementando um CRUD completo.

---

## 🚀 Funcionalidades

- Listagem de fotografias
- Visualização detalhada de cada imagem
- Cadastro de novas fotos
- Edição e atualização de registros existentes
- Exclusão de fotografias
- Upload de imagens
- Interface responsiva e organizada com HTML + CSS

## 📦 Como rodar o projeto

### 1. Clone o repositório

```
git clone https://github.com/Vitiiv/space-projetc_front.git
```

### 2. Acesse a pasta do projeto

```
cd space-projetc_front
```

### 3. Crie e ative o ambiente virtual

```
python -m venv .venv
.\.venv\Scripts\activate  # Windows
source .venv/bin/activate # Linux/Mac
```

### 4. Instale as dependências

```
pip install -r requirements.txt
```

### 5. Rode as migrações

```
python manage.py migrate
```

### 6. Inicie o servidor

```
python manage.py runserver
```

Acesse no navegador:
👉 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
